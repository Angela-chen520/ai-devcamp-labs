          VideoLearn AI 7 重企業級資安防禦檢核機制
        

        
      

      

        

          
          

            1. SSRF 伺服端請求偽造防護 (Intranet IP Protection)
            
強制即時解析 URL DNS，阻斷存取 127.0.0.1、10.x、172.16-31.x、192.168.x 及雲端服務 Metadata (169.254.169.254)。

          

        

        

          
          

            2. 二進位檔案 Magic Bytes 特徵碼深度檢驗 (Anti-Malware Scanner)
            
嚴格檢核影音二進位標頭（MP4 ftyp, WebM/MKV, MP3 ID3, WAV RIFF），主動阻斷偽裝成影音的 Windows PE (MZ) 木馬、Linux ELF 病毒與腳本。

          

        

        

          
          

            3. 13 大跨國平台白名單驗證 (Domain Whitelist)
            
嚴格限定 YouTube, TikTok, FB, X, IG, Twitch, Bilibili, Vimeo, SoundCloud, Reddit, LinkedIn, Pinterest 網域，杜絕釣魚網站。

          

        

        

          
          

            4. 指令注入與 Shell 跳脫防禦 (Command Injection Guard)
            
在調用解碼子進程時，過濾 ;, |, &, `, $, 換行符等危險跳脫字元，防止惡意指令注入。

          

        

        

          
          

            5. 提示詞注入與越獄清洗 (Prompt Injection Sanitizer)
            
即時過濾 ignore previous instructions、system prompt leak 等惡意指令，確保 AI 導師安全可控。

          

        

        

          
          

            6. 沙盒進程隔離與無外部特權
