# Multilingual Customs & Baggage Localization (多語系海關與行李用語對照指引)

Adapt terminology seamlessly according to the traveler's preferred language variety:

## 1. Terminology Matrix: British English (en-GB) vs American English (en-US)

Always respect the nuanced distinctions between British and American border terminology:

| Concept / Item | British English (`en-GB`) | American English (`en-US`) |
|---|---|---|
| 託運行李 | Hold luggage / Checked luggage | Checked baggage / Checked bag |
| 隨身/手提行李 | Hand luggage / Cabin bag | Carry-on luggage / Carry-on bag |
| 邊境與海關機關 | Border Force / HMRC | CBP (Customs & Border Protection) |
| 海關申報通道 | Red Channel (Goods to declare) | Red Channel / Customs Inspection |
| 常用止痛退燒藥 | Paracetamol | Acetaminophen / Tylenol |
| 藥局/藥房 | Chemist / Pharmacy | Pharmacy / Drugstore |
| 電子煙 | E-cigarette / Vape | E-cigarette / Vape |
| 醫療處方 | Doctor's prescription | Doctor's prescription |
| 申報單 | Landing card / Customs declaration | Customs Declaration Form 6059B / MPC |

## 2. Asian Languages Terminology

### Traditional Chinese (`zh-TW`)
- 託運行李、隨身行李、紅線應申報檯、綠線免申報檯、海關申報單、自用免稅額度、處方箋、成藥、非洲豬瘟防疫檢疫。

### Japanese (`ja-JP`)
- 託運行李: 預け入れ手荷物 (Azukeire tenimotsu)
- 隨身行李: 機内持ち込み手荷物 (Kinai mochikomi tenimotsu)
- 海關: 税関 (Zeikan)
- 紅線應申報通道: 赤の課税通路 (Goods to Declare)
- 綠線免稅通道: 緑の免税通路 (Nothing to Declare)
- 申報單: 携帯品・別送品申告書 (Customs Declaration) / Visit Japan Web
- 動物/植物檢疫: 動物検疫所 / 植物防疫所

### Korean (`ko-KR`)
- 託運行李: 위탁 수하물 (Checked baggage)
- 隨身行李: 기내 수하物 / 휴대 수하물 (Carry-on)
- 海關: 세관 (Customs)
- 申報櫃檯: 세관 신고대 (Customs declaration desk)
- 申報單: 여행자 휴대품 신고서

## 3. Communication Guidance (多語諮詢應對規範)

- **自動適應母語**: 旅客以何種語言提問（包括英式英文、美式英文、繁體中文、日語等），即以相應語言及正確地區術語進行回覆。
- **雙語溝通小卡**: 當為旅客產出海關溝通小卡時，同時提供「旅客母語」與「目的國官方語言」的精準雙語對照，協助旅客無縫通關。
