# Customs Declaration Guidance & Officer Phrase Card (海關報關流程教學與通關小卡)

When a traveler carries items that require declaration or payment of duty, present the structured 4-layer tutorial below:

## 1. Layer 1: Golden Rule of Customs Peace-of-Mind (海關安心黃金法則)

Always highlight this prominent principle to alleviate traveler anxiety:
> 🔔 **【海關安心黃金準則】：「主動申報不罰，隱匿不報重罰！」**
> 只要在入境時主動選擇「紅線應申報檯 (Red Channel)」，即使不慎帶了超額物品或不確定是否合格的農產品，海關官員只會依法核算稅額或辦理銷毀/退運，**絕對不會對您處以罰款或留下不良紀錄**！切勿心存僥倖走綠線。

## 2. Layer 2: 4-Step Customs Declaration Journey (報關四階段全旅程引導)

Guide the traveler through the timeline step-by-step:

```text
[步驟 1: 出發前] ──▶ [步驟 2: 航班中/抵達前] ──▶ [步驟 3: 抵達與動線] ──▶ [步驟 4: 查驗與繳稅]
發票/處方箋準備       填妥紙本或數位申報單         走紅線應申報櫃檯           核稅開單、刷卡繳納
```

### 步驟 1：出發前準備 (Pre-flight Preparation)
- **購物憑證**: 保留所有需申報物品的原始購買發票、免稅店收據（Receipts / Invoices）。
- **醫療文件**: 若攜帶處方藥或管制藥品，請備妥合格醫院開立之英文/中英文醫師診斷證明書或處方箋正本。
- **預先線上申報（若適用）**:
  - 日本：登入 **Visit Japan Web** 完成「入境審查與稅關申報」並取得 QR Code。
  - 臺灣：可於手機填寫「入境旅客線上申報系統」或下機後填寫紙本。
  - 美國：可使用 **Mobile Passport Control (MPC)** App 或機上紙本藍色申報單 6059B。

### 步驟 2：飛行中或抵達前申報單填寫 (In-flight / Pre-arrival Declaration)
- 於飛機上向空服員領取紙本「中華民國海關申報單」或入境國之「Customs Declaration Form」。
- 在「是否攜帶超過免稅限額之菸酒/商品/貨幣」欄位勾選 **【是 (YES)】**，並於背面條列填寫品名、數量與預估價值。

### 步驟 3：抵達與機場動線導引 (Arrival & Airport Navigation)
- 領取行李後，注意頭頂指示牌：
  - 🟢 **綠線檯 (Green Channel)**: 標示「免申報 (Nothing to Declare)」——**切勿走此通道！**
  - 🔴 **紅線檯 (Red Channel)**: 標示「應申報 (Goods to Declare)」——**請推著行李直行前往紅線櫃檯**。
- 將護照與填妥之申報單（或數位申報 QR Code）遞交給紅線值勤海關官員，主動說明攜帶之物品。

### 步驟 4：海關查驗、計稅與繳納放行 (Customs Inspection & Payment)
- **開箱檢視**: 海關官員核對物品與發票收據。
- **稅金核算**: 海關系統依據完稅價格開立「海關進口稅費繳納證」。
- **現場繳款**: 現代化機場紅線櫃檯均支援 **信用卡 (Visa/Mastercard/JCB)、行動支付或當地現金** 繳納。
- **繳費放行**: 繳納完畢領取正式稅單收據，行李全數合法放行出關，安心享受旅程！

## 3. Layer 3: Duty & Tax Estimator Guide (稅金預估與計算原則)

Explain how import duties are composed:
1. **完稅價格 (Customs Value / Dutiable Value)** = 物品購買價格（換算當地貨幣）+ 運費/保險費（若有）。
2. **進口關稅 (Import Duty)** = 完稅價格 × 該品項海關進口稅率（一般精品約 5%~10%，化妝品 0%~5%，成衣 10%~12%）。
3. **貨物稅 / 菸酒稅 (Commodity / Excise Tax)**:
   - 酒類：依酒精濃度或公升數計算（例如威士忌每公升每度蒸餾酒稅額，或按定額計）。
4. **營業稅 / 增值稅 (VAT / Sales Tax)** = (完稅價格 + 進口關稅 + 菸酒/貨物稅) × 5%（臺灣為 5%，各國約 5%~20%）。

## 4. Layer 4: Customs Officer Bilingual Phrase Card (全螢幕海關溝通小卡)

When the traveler is arriving in a country where they do not speak the local language fluently, generate an instant, clear flashcard they can display on their smartphone screen directly to the customs officer.

Format of the Flashcard:
```text
┌────────────────────────────────────────────────────────────┐
│ 🛃 CUSTOMS DECLARATION / 税関申報提示卡                     │
├────────────────────────────────────────────────────────────┤
│ [Destination Language - Large Bold Text]                   │
│ "Hello Officer, I have items to declare for personal use: │
│  - [Item Name]: [Quantity] (Value: [Price])               │
│  I would like to declare them and pay the required duties."│
├────────────────────────────────────────────────────────────┤
│ [Traveler's Native Language Translation]                   │
│ （長官您好，我攜帶了以上自用物品欲辦理申報並繳納相應關稅）  │
└────────────────────────────────────────────────────────────┘
```
This guarantees smooth communication without language barriers!
