## 1. 系統核心價值與隱私承諾

出國旅遊或商務出差時，許多旅客常因各國複雜多變的海關法規、免稅額上限、藥品管制與動植物檢疫禁令感到焦慮。更嚴重的是，每年都有大量旅客因不慎攜帶肉製品（如非洲豬瘟禁令）、電子菸或超額現金，而在抵達目的地機場時面臨**數十萬元罰鍰、沒收物品、拘留甚至驅逐出境**。

本系統為解決上述痛點而打造，並秉持以下最高準則：

### 🔒 零個資收集 (Zero-PII Privacy First)
* **無需護照、身分證與真實姓名**：旅客查詢行李規範時，系統絕不要求、亦絕不留存任何個人身分證件。
* **本地正則雙層清洗 (Stage 1 Regex Sanitizer)**：即時在瀏覽器前端與後端攔截並替換各國護照號碼、臺灣身分證號、電話、信用卡號與電子郵件為 `[REDACTED_*]` 標記，完全隔絕機敏資料傳遞給大型語言模型。
* **安心隱私標籤**：若使用者不慎輸入個資，系統會主動顯示隱私聲明，保障旅客資料安全。

### ⚖️ 三級動態語氣分級 (Dynamic 3-Tier Tone)
依據物品法規危險程度，自動調校回應風格：
* 🟢 **綠色（完全合規）**：語氣溫和親切、安心提醒。
* 🟡 **黃色（超額應稅/限制物品）**：委婉建議自用限額、提醒主動走紅線申報以避免受罰。
* 🔴 **紅色（絕對禁止攜帶之違禁品）**：嚴肅警告法律後果、列出重罰金額、指導立即棄置於海關農檢棄置箱。

### 🗺️ 18 國全球法規、文化禁忌與在地天候整合
內建臺灣、日本、韓國、加拿大、義大利、荷蘭、新加坡、泰國、越南、菲律賓、馬來西亞、法國、澳洲、西班牙、希臘、美國、英國、香港等 18 國完整法規資料庫、旅客人身管理條例與旅遊穿搭氣象。

* **Python 版本**：Python 3.10 或更新版本

本專案已提供環境變數範本 `capstone_customs_agent/.env.example`。請依據您的模式建立 `.env` 檔案：

```bash

cp capstone_customs_agent/.env.example .env
```

在 `.env` 中填入金鑰（二選一）：

* **選項 A：Google AI Studio 免費 API Key（最推薦、最快）**
  ```env
  GEMINI_API_KEY=AIzaSy...您的免費APIKey...
  GOOGLE_GENAI_USE_VERTEXAI=False
  ```
  *(可於 [Google AI Studio](https://aistudio.google.com/) 免費獲取)*

* **選項 B：Google Cloud Vertex AI 企業模式**
  ```env
  GOOGLE_GENAI_USE_VERTEXAI=True

  ```

### 4.3 分頁二：行李申報智慧核驗

這是系統的核心業務工作台，包含三大功能區塊：

#### 步驟 1：選擇出入境航線與日期
* **出發地與目的地選單**：支援 18 個主要出入境國家/地區。選單變更時，頂部航線指示牌（例如 `TPE ✈️ KIX`）將同步動態更新。
* **出發與回國日期選擇**：
  * 當旅客選定旅遊日期後，系統會**自動發送請求查詢目的地氣象預報**。
  * **氣象資訊卡**：即時顯示目的地氣候特徵（例如東京春季 14°C~22°C、日夜溫差大）、降雨提醒以及**具體行李打包建議**（洋蔥式穿法、防風外套、折疊傘）。

#### 步驟 2：輸入攜帶物品
* **熱門物品快速勾選標籤**：
  * 點擊標籤（如：`威士忌 700ml 4瓶`、`處方慢性病藥品 2個月份`、`加熱菸 2條`、`肉鬆蛋黃酥 1盒`、`日幣現鈔 1,500,000円`）可將常見品項一鍵加入清單。
* **自訂詳細清單輸入框**：
  * 支援自由文字輸入。
  * 🛡️ **Zero-PII 安全過濾機制**：若在此輸入護照號碼（如 `314567890`）或身分證號（如 `A123456789`），系統會立即在前端與後端清洗遮蔽為 `[REDACTED_PASSPORT]`，保護旅客個資絕不外洩。

#### 步驟 3：智慧核驗與等待計時器
* 點擊 **「✈️ 即刻開始智慧行李核驗」** 按鈕。
* **預計等待計時器**：畫面立即浮現航空雷達掃描動畫，並動態顯示「預估剩餘時間：約 4~6 秒」，緩解旅客等待焦慮。

#### 步驟 4：審查報告呈現
1. **通關風險評級戳印**：
   * 🟢 **符合自用規範 (Safe)**
   * 🟡 **超額需申報 (Declaration Advised)**
   * 🔴 **嚴正警告違禁品 (Prohibited / Illegal)**
2. **AI 多代理人法規深入分析**：
   * 條列分析各項物品於目的國的法律依據與裁罰基準。
3. **關稅與稅費試算卡**：
   * 試算超額免稅額度（例如：臺灣免稅 1 公升，攜帶 4 瓶 0.7 公升共 2.8 公升，超額 1.8 公升）。
   * 列出酒精度、進口關稅率、菸酒稅額與營業稅試算總額。
4. **即席雙語海關溝通小卡 (Customs Phrase Card)**：
   * 為旅客產生目的國母語對照卡（例如前往日本自動生成中日對照；前往法國生成中法英對照）。
   * 內容包含旅客主動配合海關查驗之宣告詞、申報物品明細、法規佐證。
   * 旅客抵達外國海關時，**只需拿出手機出示該卡片螢幕**，即可消除語言隔閡，從容通關。

### 4.4 分頁三：入境文化禮儀與法規禁忌

專為跨國旅客設計的「法律避雷針與禮儀手冊」，可透過下拉選單切換 18 國，即時掌握：

* ⚖️ **重大管理法規與刑責警示（避免罰款與拘禁）**：
  * **新加坡**：嚴格禁止攜帶或販售口香糖（違者罰款高達 10,000 新幣）；亂丟垃圾或地鐵飲食處以高額罰款與鞭刑警示。
  * **日本**：嚴格管制未登記之無人機飛行；未經許可攜帶動植物肉品最高處 3 年以下有期徒刑或 300 萬日圓罰金。
  * **泰國**：對任何毀損或侮辱泰皇、泰銖紙幣之行為處以重刑；電子菸全面違法；涉毒品走私最高判處死刑。
  * **義大利 / 法國**：搭乘大眾運輸務必先打票（未打票罰款 50~100 歐元）；購買仿冒名牌精品最高面臨 10,000 歐元罰鍰與刑事偵辦。
  * **菲律賓 / 越南 / 澳洲**：澳洲邊境對任何未申報有機物與種子零容忍，當場開罰 6,260 澳幣並當場註銷簽證驅逐出境。
* 🤝 **當地文化風俗與日常禮儀**：
  * 各國小費習慣（美加 15~20%、日韓無小費文化、歐洲酌留零錢）。
  * 寺廟或教堂參拜穿著禁忌（不可穿無袖露肩、短裙短褲）。
  * 拍照與肖像權禁忌（禁止拍攝各國機場海關、軍事管制區；瑞士/德國未經同意不可拍攝他人正臉）。

### 4.5 分頁四：機場海關報關流程教學

為解除旅客對「報關會不會被抓或留下紀錄」的恐懼，本頁面詳細拆解報關標準流程：

#### 🌟 海關黃金第一準則：主動申報絕不罰！
* **安心原則**：海關處罰的對象是「隱匿未申報並企圖走綠線免申報檯」的旅客。
* **只要旅客在通關前主動向海關出示物品並填寫申報單，即便攜帶物品超出免稅額，最壞情況僅需補繳稅款，或依法自願放棄物品，絕不會面臨沒收罰款或刑事裁罰！**

#### 🚶 時序式通關四階段流程：
1. **出發前行前檢視**：使用本系統核算行李，將超額應稅物品與購買憑證（發票、收據）集中放置。
2. **機上填寫申報單**：於機上或抵達大廳領取填寫「海關申報單 (Customs Declaration Form)」，若有超額物品勾選「是 (Yes)」。
3. **選擇海關通道**：
   * 🟢 **綠線通道 (Green Channel / Nothing to Declare)**：隨身行李與託運行李完全符合免稅規定、未帶任何動植物檢疫品、現金未達管制上限。
   * 🔴 **紅線通道 (Red Channel / Goods to Declare)**：攜帶超過免稅額物品、任何疑似需檢疫動植物、商務樣品、超額現金外幣，或「對攜帶物品規範有疑慮者」。
4. **查驗與繳納稅費**：關員核對物品與發票，開立繳款單，於機場海關銀行櫃檯繳納稅費後順利提領放行。

## 6. API 金鑰安全規範與隱私防護

在開源與公開部署過程中，保護機敏金鑰與旅客隱私是不可妥協的底線：

### 🛡️ API 金鑰零外洩機制
1. **`.gitignore` 自動屏障**：
   專案根目錄 `.gitignore` 已嚴格配置：
   ```gitignore
   .env
   .env.*
   *.env
   *.env.*
   ```
   所有放置於 `.env` 或 `capstone_customs_agent/.env` 的金鑰均不會被 `git add` 追蹤或推送到 GitHub。
2. **範本安全檔 (`.env.example`)**：
   版本庫中僅保留結構範本，無任何真實金鑰。
3. **程式碼內部絕無 Hardcode 金鑰**：
   所有程式碼一律透過 `os.environ.get()` 動態載入環境變數。

### 🛡️ 旅客隱私防護機制
1. **Zero-PII 正則過濾**：
   在任何文字送往 LLM 之前，`guardrails.clean_pii_local()` 會自動遮蔽全球護照號碼與國民身分證號。
2. **無狀態記憶原則**：
   伺服器不建立任何將旅客身分與查詢內容關聯的持久化資料庫，查詢結束即釋放。

## 8. 常見問題與障礙排除 (FAQ)

### Q1：啟動 `./run_web.sh` 時出現 `Address already in use` (連接埠 8000 被佔用)？
**解法**：您可以指定其他連接埠啟動，例如：
```bash
PORT=8080 ./run_web.sh
```
或找出佔用 8000 連接埠的程序並關閉：
```bash
lsof -ti:8000 | xargs kill -9
```

### Q2：如果在國外機場入境時，發現自己真的不小心多帶了酒或名牌包，該怎麼辦？
**海關自救黃金守則**：
1. **千萬不要走綠線**！走綠線一旦被海關米格魯檢疫犬嗅出或被 X 光機查獲，將直接認定為「匿報」，處以沒入加高倍罰鍰。
2. **立刻走向紅線申報櫃檯**：主動向海關關員出示物品並說明「我不確定這是否超額，我想要主動申報」。
3. 根據海關法規，只要主動申報，最壞的結果就是繳納進口稅，完全合法且絕不罰款！

### Q3：如果我不小心把含有個人真實姓名的訊息貼進輸入框，會被送出去嗎？
**解法**：本系統在前端與後端建置雙重 Zero-PII 防護網。無論是護照號碼、身分證字號或聯絡資訊，均會被在地正則運算元即時抹除為 `[REDACTED_*]` 替代符，絕不會將個人隱私傳送給大型語言模型或任何外部伺服器。
